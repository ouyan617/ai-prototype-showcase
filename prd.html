空间预约系统 · 需求文档与系统规则逻辑

版本：V1（管理端 + 小程序端 合并版）　|　日期：2026-08-17　|　依据材料：管理端需求文档、小程序需求文档、空间预约管理端原型、空间预约小程序端原型
本文档依据空间预约系统相关材料整合编写，遵循“功能概述 → 业务流程 → 详细规则表 → 状态流转 → 异常清单”的结构，将管理端与小程序端两套需求合并为一份完整需求文档与系统规则逻辑。技术字段命名由开发团队依据本文档中文语义自行定义。

第1章 概述

1.1 目的与范围

目的：把建科大楼「空间预约」能力从管理端配置延伸到用户小程序自助预约，打通“管理端配置 → 小程序预约 → 订单回流 → 管理端留痕”的闭环。

范围：

  • 管理端：空间产品预约状态配置、预约时间模板管理、空间预约时间配置（时刻表/日历表）、预约历史（临时关停/重新配置）。
  • 小程序端：场地浏览与筛选、收藏、选时段预约、预约成功、正在使用（计时/碳电计量）、订单（未出行/历史）。
  • 跨端：小程序展示数据全部来源于管理端配置；小程序产生的订单回流到管理端预约历史。

1.2 角色

角色端职责
空间管理员管理端维护空间产品、配置是否可预约与预约时段模板、查看预约历史、临时关停/重新配置。
普通用户（员工/访客）小程序端浏览场地、筛选、收藏、选时段预约、使用计时、查看个人订单。
系统（联动）两端管理端配置 → 小程序展示；小程序下单 → 管理端历史留痕；临时关停/固定占用 → 小程序实时不可约。

1.4 核心数据模型

实体关键字段（中文语义）来源/说明
空间产品空间名称、空间编号、空间类型、空间面积、可容纳人数、楼层、所属空间、预约状态、出租/自用、交易类型、使用状态、产品标签、列表操作列、可预约配置（新增）、当前模板标识（新增）管理端资产管理列表字段；新增“可预约配置”与“当前模板标识”。
预约模板编号、名称（唯一）、绑定空间集合、工作日历（默认2026法定工作日）、时刻表（单元格状态）、统一配置（每日/工作日/非工作日）、其他设置（提前/超时/提前天数/最长时长/确认方式）管理端预约设置。
时段单元模板标识、空间标识、日期、小时、状态（可预约/固定占用/清除）由模板与空间绑定后展开；小程序按此展示可约/不可约。
预约订单编号、空间标识、用户微信标识、日期、开始时间、结束时间、状态（待使用/使用中/已完成/已取消）、来源=小程序小程序产生；回流管理端预约历史。
说明：只有已上架的空间产品才可在基本信息中选择“可预约/不可预约”。选择“可预约”后，若尚未配置预约模板，资产管理列表的“预约状态”显示“未配置”；点击“未配置”进入空间预约时间配置页，选择预约时间模板。选择“不可预约”则直接显示“不可预约”。

1.5 统一着色规范（两端强制一致）

颜色含义
绿 #52c41a可预约
红 #ff4d4f固定占用 / 已预约占用
橙 #fa8c16已使用·预约且实际使用
褐 #6b4423未使用·预约但未实际使用
淡蓝 #e6f7ff法定工作日（未配置前）
淡灰 #f5f5f5未配置/不可用
设计决策：管理端原型中“已使用”曾使用灰色显示，与需求文档及图例不一致。统一规定：已使用一律橙色，未使用一律褐色。管理端原型需同步修正样式类与图例。

第5章 设计决策与规则说明

本章汇总需求文档、管理端原型、小程序原型之间的不一致点，并给出最终设计决策。优先级：需求文档 > 统一设计规范 > 原型；原型仅作交互参考，冲突以需求文档与设计规范为准。

5.1 预约状态真源

本版本“是否可预约”为独立配置字段，上架时按空间属性初始化默认值：自用→不可预约；出租且收租金→不可预约；出租且开放→可预约。可预约配置为可预约但无模板时，预约状态显示“未配置”；绑定模板后显示“可预约”。管理员可手动覆盖默认值。

5.2 时刻表时间边界

管理端需求文档原要求时刻表最早/最晚由“每天预约开放时间”动态决定，管理端原型写死 0:00–24:00。经确认，本版本统一按 0:00–24:00 实现，不再按空间产品独立配置边界。

5.3 已使用着色颜色

需求文档：已使用=橙色，未使用=褐色。管理端原型曾把“已使用”样式类设为灰色。最终统一为：已使用一律橙色，未使用一律褐色。管理端原型需同步修正样式类与图例。

5.4 小程序时段可选范围

小程序原型日期固定未来 7 天、时间 0–23 整点，未受管理端约束。最终规则：日期默认未来 7 天，受工作日历+“场地X天前可预约”约束；时间受“每天开放时间”+“最长区间”约束；越界不可选/不可提交。

5.5 空间类型分类

管理端：办公空间 / 会议室 / 展厅。小程序筛选：办公空间 / 设备用房 / 会议室 / 阅览座。最终统一类型字典为 {办公空间, 会议室, 展厅, 设备用房, 阅览座}，小程序筛选对齐；阅览座纳入类型筛选。

5.6 碳电计量公式

小程序端碳电计量按灵动应用同款公式计算，具体系数与展示单位由技术团队维护，需求文档不写公式。

5.7 空间-模板绑定关系

一个空间产品仅允许绑定一个预约模板。若尝试将已绑定其他模板的空间再次绑定，必须弹出冲突提示并阻止绑定。

5.8 已对齐/一致项

  • “重新配置”无绑定树、单空间修改、含“选择模板”弹窗 —— 原型与需求文档一致。
  • 临时关停“日期/时段无范围限制” —— 原型与需求文档一致。
  • 未配置日历 → 默认不可预定 —— 原型与需求文档一致。
  • 休息区永远绿色可预约 —— 已确认。
  • 订单超时未开始自动转褐 + 微信服务通知 —— 已确认。
  • 人工确认按键保留，但当前版本实际均为自动审批 —— 已确认。
